# Demo 2 — Support RAG Agent

**Label: Demo — fictional data. This is not client work.**

A fictional outdoor-gear store (Harbor Outdoor Gear, fictional) support agent answers only from its own help docs, cites the source for each answer, refuses out-of-scope questions, and hands low-confidence cases to a human. It never invents a shipping time, refund rule, or warranty term.

## How to run

```bash
cd demo2-support-rag
python3 support_agent.py
python3 -m unittest test_support_agent.py -v
```

Outputs:
- `outputs/qa_log.csv` — every question, retrieved sources, answer/handoff, reason
- `outputs/summary.json` — counts by outcome and question IDs per outcome

## Pipeline

Question → retrieve top 3 docs (keyword overlap) → confidence check → answer with citation, or clarify / hand off

Hard rules in code, not just a prompt instruction:
- No refund approval, no order change, no cancellation — those always hand off.
- No answer without a source for a policy question.
- A grounded answer quotes a sentence from the cited doc; nothing is invented.
- Every handoff carries question, sources found, missing info, reason, and a suggested human reply.

In a production version, retrieval would use embeddings and drafting would use an LLM. In this demo retrieval is deterministic keyword overlap and the answer is a cited excerpt from the retrieved doc, so the run is fully reproducible and testable; the retrieval gate, citation rule, and handoff are the parts being demonstrated. Do not list LLM retrieval or LLM drafting as built experience from this demo alone until an embedding + LLM step is actually added and tested.

## Walkthrough — three questions to show a buyer

- **Q02 — Answered, cited [D02 Returns]:** "How many days do I have to return an unused item?" → "Returns are accepted within a 30-day window of delivery for unused items in original packaging."
- **Q07 — Clarified, not guessed:** "What is the time window to return an item or exchange an item?" → matches both D02 Returns and D09 Exchanges, so it asks which applies instead of picking one policy.
- **Q09 — Handed off:** "Can you approve a refund for a tent I used on a trip and returned after 90 days?" → refund approval always hands off, with the question, sources found, and a suggested human reply logged.

## Acceptance criteria (checked by the tests)

- All 10 questions logged, in input order
- Distribution: 6 answered, 2 clarified, 2 handed off
- Every in-scope answer cites its expected doc, and the quoted sentence appears verbatim in that doc
- Zero invented policies in the 10 answers
- Both out-of-scope questions hand off, neither gets a guessed policy answer
- Both ambiguous questions clarify or hand off instead of guessing
- Refund / cancellation / order-change requests always hand off, even in isolation
